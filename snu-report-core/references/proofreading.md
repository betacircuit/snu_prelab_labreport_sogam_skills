# 오탈자 검증

보고서를 보내기 전에 아래 순서를 **빠짐없이** 한다. 도구가 잡는 것과 사람 눈으로만 잡히는 것을 나눠서 본다.
`$E`는 엔진 `scripts/` 폴더다.

## 순서
1. **원고 검사**: `python $E/proof.py <원고.md>` — 걸린 것을 원고에서 고치고 다시 돌린다. build.py도 빌드할 때 같은 검사를 돌려 `오탈자 ⚠`로 보여 준다.
2. **문체 검사**: `python $E/style_check.py <원고.md>` (writing.md).
3. **빌드**: `python $E/build.py courses/<과목>/labNN <prelab|report> --pdf`. 빌드 결과 docx를 다시 읽어 제목 번호, 풀리지 않은 참조, 남은 `[TODO]`를 `결과물 ⚠`로 보여 준다.
4. **결과물 검사**: `python $E/proof.py build/<파일>.docx --strict` — 통과할 때까지 1로 돌아간다.
5. **대조 읽기** (도구가 못 잡는 것): 원고를 문장 단위로 다시 읽으며 아래 "눈으로 볼 것"을 하나씩 확인한다.
   - 가능하면 다른 에이전트에게 원고와 "눈으로 볼 것" 목록만 주고 따로 교정을 맡긴다. 내가 쓴 글은 내 눈에 틀린 곳이 안 보인다.
6. **미리보기 PDF 전 페이지**: 제목 번호, 표·그림 캡션, 수식 첨자가 제대로 나왔는지 이미지로 본다.

| 표시 | 예 → 고칠 꼴 |
|---|---|
| `[조사]` | 조건를 → 조건을, 출력로 → 출력으로, 저항와 → 저항과 (형태소 분석 kiwipiepy로 명사일 때만) |
| `[반복]` | "확인 확인", "의 의" |

| `[칩·게이트]` | 7402(XOR) → 7402는 NOR, 7486(NOR) → 7486은 XOR |
| `[쉼표]` | NOT AND OR → NOT, AND, OR |
| `[맞춤법]` | 되요, 몇일, 할수 있, 할때, 역활, 갯수, 이였다, 측정 값 → 측정값 |
| `[맞춤법]` 률/율 | 오차률 → 오차율 (모음·ㄴ 받침 뒤 '율'), 확률 |

| `[기호]` | 본문에 F0과 $F_0$이 섞임 → 수식으로 통일 |
| `[본인 글]` | "사용자가 촬영한", "AI", "제공된", "수정 전 코드" → 본인이 쓴 글로 (빌드가 멈춘다) |
| `[수식]` | 문장 속 분수·긴 식, 한 줄에 식 셋 이상 → `$$`로 줄을 나눈다 |
| `[표기]` | "atan2로 구하였다", `np.angle`, 수식 속 `\operatorname{atan2}` → 교재 표기 $\tan^{-1}$(구간 나눔), $\angle$ (빌드가 멈춘다). 기전연에서 본인 코드의 함수는 `` `atan2` ``처럼 코드 글꼴로만 |
| `[표기 권장]` | `\arctan` → $\tan^{-1}$, $i\omega$ → $j\omega$, `20\log` → $20\log_{10}$ |
| `[용어]` | 음의 되먹임 → negative feedback, 디커플링 → decoupling, 오프셋 → offset, 슬루율 → slew rate (writing.md 용어) |

| `[참조]`, `[표시]` (docx) | `??fig:x`, 남은 `[TODO]` |

잡힌 것이 실제로 맞는 표현이면 (예: 고유명사) 그대로 두고 사용자에게 한 줄로 알린다.

## 눈으로 볼 것
- **기호와 첨자**: $F_0$/$F_1$/$F_2$, $A_2A_1A_0$처럼 첨자 번호가 표·본문·그림에서 같은 뜻인가. 정의 문장("$F_0 = 1$이면 $A > B$")과 표 행이 맞는가
- **게이트 이름**: 본문의 NOR/XOR/NAND가 그림(figures.md 표)과 칩 번호와 같은가
- **수치**: 본문 숫자가 표·evidence.yaml·스크립트 출력과 같은가. 단위와 자릿수
- **문항 번호**: 원고의 가이드북 번호와 문항 대응표가 같은가 (4.2와 4.3이 바뀌지 않았나). 출력 제목에는 절 번호가 한 번만 있는가 (`2.3) 3)` 금지)
- **내용 오류**: 게이트 개수·종류 설명이 회로와 맞는가 (예: $E_i = A_iB_i + \overline{A_i}\,\overline{B_i}$는 AND 2개, OR 1개에 NOT 2개가 더 든다)
- **용어 통일**: 한 번 정한 용어를 끝까지 같게 (writing.md 용어)
- **영문**: 대소문자(MSB/LSB, Vcc → $V_{CC}$), 하이픈(3-bit), 약어
