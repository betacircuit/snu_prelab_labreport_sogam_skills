# 데이터와 근거

보고서의 모든 수치와 관찰은 원자료로 거슬러 올라갈 수 있어야 한다.
(실험 보고서 작성 지침을 이 skill에 맞게 줄인 것)

## 만들지 않는 것
- 측정값, 관찰 결과, 실험 조건, 실패·재실험 이력, 사진
- 가이드북 지시("Measure …")를 실제로 한 일처럼 바꿔 쓰기
- 다른 Lab·다른 사람 보고서의 측정값과 결론
- 빈칸을 0이나 이론값·평균값으로 채우기, 반복 측정 없는 표준편차, 근거 없는 ± 값

## 묻기 전에 자료로 판단한다
사용자는 필요한 자료(측정 시트 등)를 이미 줬다고 생각한다. 자료로 알 수 있는 것은 묻지 않는다.
- 표기 해석: 시트 머리글("출력기준" 등), 이론값 배치, 가이드북 정의가 서로 맞는 해석을 고르고, 실험 방법에 한 문장으로 밝힌다.
- 시트의 이론값이 다시 계산한 값과 반올림 수준으로 다르면 다시 계산한 값을 쓰고 넘어간다.
- 자료에 없는 부수 정보(함수 발생기 주파수, 칩 계열, 사진)는 그 정보가 필요한 문장을 쓰지 않는다.
- 관찰 기록이 없는 고찰 문항은 회로와 이론으로 설명한다. 관찰했다고 쓰지는 않는다.
- 사용자가 대화에서 알려 준 사실(예: "LED랑 330 Ω 달고 했어")은 자료로 쓴다.

묻는 경우는 하나뿐이다: 슬라이드가 반드시 넣으라고 한 결과가 자료 어디에도 없을 때. 초안을 끝까지 쓴 뒤, 빠진 것만 한 번에 묻는다.

## 근거 수준을 섞지 않는다
| 구분 | 뜻 | 문장 |
|---|---|---|
| 측정 | 계기로 잰 값, 직접 본 LED 상태 | "측정하였다", "관찰하였다" |
| 판독 | 스코프 화면·사진에서 읽은 값 | "화면에서 읽은 값은" |
| 계산 | 원자료로 계산한 값 (식을 보인다) | "~로 계산된다" |
| 이론 | 모델·datasheet 값 | "datasheet 전형값은" |
| 가정 | 계산에 둔 가정 (V_F = 2.0 V 등) | "~로 두면" |
| 해석 | 위 값들로부터의 설명 | "~로 보인다", "~가능성이 크다" |

- 여러 원인 중 데이터로 가를 수 없는 것을 확정 원인으로 쓰지 않는다.
- 칩 계열을 모르면 다른 계열의 datasheet 값을 확정적으로 적용하지 않는다. 가이드북에 실린 datasheet는 "가이드북의 74LS00 datasheet 기준"처럼 출처를 밝혀 쓴다.

## 근거표 `report/evidence.yaml`
```yaml
methods:            # 측정 방법, 표기 해석 (M01 …)
records:            # 원자료 한 줄 = 한 조건 (D01 …)
  - id: D01
    item: "8.2.1"
    label: "tPLH"
    condition: "NAND 1개"
    values: [12.4, 12.0, 12.4]      # 반복 측정값 그대로
    unit: ns
    kind: 측정                       # 측정 | 판독
    source: "raw/data.xlsx Sheet1!B2:D2"
derived:            # 계산값 (C01 …) — formula로 다시 계산
  - id: C01
    formula: "r1(mean(D01)) + r1(mean(D02))"   # r1 = 표에 적힌 소수 첫째 자리 값
```
- `python $E/evidence.py dump raw/data.xlsx` 로 셀 좌표·수식을 보고 옮긴다.
- 조원이 측정·공유한 자료는 `source`에만 이름과 날짜를 적는다. 보고서 본문에는 쓰지 않는다.
- 원자료(`report/raw/`)는 고치지 않는다.

## 작업용 표시
작성 중 메모로만 쓰고, 사용자에게 주는 docx에는 남기지 않는 것이 원칙이다. `build.py`가 초안에서 형광펜으로 보여 준다.

| 표시 | 뜻 | `--final` |
|---|---|---|
| `[TODO: …]` | 아직 안 쓴 곳 | 실패 |
| `[미제공: …]` | 자료를 못 받음 | 실패 |
| `[확인 필요: …]` | 자료끼리 충돌 | 실패 |
| `[판독 불가: …]` | 사진·화면에서 읽을 수 없음 | 실패 |
| `[미측정: …]`, `[미수행: …]` | 사용자가 안 했다고 확인함 | 경고 (문장으로 풀어 쓴다) |
