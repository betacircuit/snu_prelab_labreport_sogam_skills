# 용어 표준

번역은 한국어로 읽었을 때 뜻이 바로 와닿을 때만 한다. 와닿지 않는 말을 굳이 옮기면 번역투가 되고, 읽는 사람도 원어로 다시 바꿔 읽는다.
전기정보·물리 과목에서 쓰는 전문 용어는 많지 않으니 이 표로 정해 두고 모든 과목 보고서에서 똑같이 쓴다.

- 이 파일이 원본이다. `proof.py`가 아래 표의 "쓰지 않는 꼴"을 읽어 `[용어]`로 알려 준다 (빌드는 멈추지 않는다).
- 표에 없는 말은 같은 원칙으로 고르고, 자주 나오면 표에 한 줄 더한다. "쓰지 않는 꼴"은 쉼표로 나눈다.
- 영어로 쓸 때도 문장은 한국어다. 영어 낱말만 그대로 두고 조사는 발음대로 붙인다 (feedback을, offset이, op-amp의).
- 한쪽을 골라 끝까지 쓴다. "negative feedback(음의 되먹임)"처럼 괄호로 덧붙이지 않는다.

## 영어로 쓸 말

| negative feedback | 음의 되먹임, 음되먹임, 부궤환, 음궤환 | 회이실 |

| op-amp | 오피앰프, 옵앰프, 연산증폭기, 연산 증폭기 | 회이실 |
| offset | 오프셋 | 회이실 |
| slew rate | 슬루율, 슬루 레이트, 슬루레이트, 변환율 | 회이실 |
| gain-bandwidth product (GBW) | 이득 대역폭 곱, 이득대역폭곱 | 회이실 |
| decoupling | 디커플링 | 공통 |

## 한국어로 쓸 말
한국어가 바로 통하고 수업에서도 그렇게 부르는 말. 영어를 음차한 꼴은 쓰지 않는다.

| 쓸 말 | 쓰지 않는 꼴 | 과목 |
|---|---|---|
| 이득 | 게인 | 공통 |
| 위상 | 페이즈 | 공통 |
| 지연, 전파 지연, 지연 시간 | 딜레이 | 공통 |
| 전류 | 커런트 | 공통 |
| 전압 | 볼티지 | 공통 |
| 저항 | 레지스턴스 | 공통 |
| 주파수 | 프리퀀시 | 공통 |
| 진리표 | 트루스 테이블 | 논설실 |
| 접지 (회로도 기호는 GND) | 그라운드 | 공통 |
| 상승 시간, 하강 시간 | 라이즈 타임, 폴 타임 | 공통 |
| 대역폭 | 밴드위스, 밴드폭 | 회이실 |
| 차단 주파수, 공진 주파수 | 컷오프 주파수, 레조넌스 | 회이실 |
| 시정수 | 타임 컨스턴트 | 회이실 |
| 정현파, 구형파, 삼각파 | 스퀘어파, 스퀘어 웨이브 | 공통 |
| 전기장, 자기장, 전위 | 일렉트릭 필드 | 기전연 |
| 유전율, 투자율 | 퍼미티비티 | 기전연 |

그 밖에 한국어로 쓰는 말 (음차 꼴이 거의 안 나와 검사하지 않음): 커패시터, 인덕터, 임피던스, 다이오드, 트랜지스터, 가상 단락, 가상 접지, 반전·비반전 단자, 오실로스코프, 함수 발생기, 브레드보드, 프로브, 전원 공급기, 벡터장, 기울기·발산·회전.
