# 자주 하는 실수

모든 과목 보고서에서 자주 틀리는 것과 이 skill이 막는 법이다. 과목별 실수는 과목 스킬 폴더의 `references/mistakes.md`에 있다
(논설실 `snu-logic-lab/`, 회로이론 `snu-circuit-lab/`, 기초전자기학 `snu-em-hw/`).
보고서를 쓰기 전에 이 파일과 그 과목 파일을 읽고, 이번 주제에 걸리는 항목을 확인한다.
- 문항이 그 실수를 묻거나(예: "왜 측정값이 다른가") 실험 결과로 드러났으면 보고서에 쓴다.
- 그렇지 않으면 보고서에 늘어놓지 않는다. 내가 틀리지 않았는지 확인하는 용도다.
- 막는 법에 "도구"라고 적힌 것은 스크립트가 자동으로 잡는다. 나머지는 직접 확인한다.

## 공통 — 보고서

| 실수 | 막는 법 |
|---|---|
| 가이드북 문항을 빠뜨림, 번호를 틀림 | 원고·문항 대응표로 원문 번호를 대조. 출력 제목에는 자동 절 번호를 한 번만 표시 (예: `2.3) 120 nF`) |
| 요구하지 않은 절을 넣음 ("실험 준비", 긴 이론 배경) | 가이드북·슬라이드가 요구한 것만. prelab은 Prelab 문항만 |
| 측정값·관찰을 지어냄, datasheet 값·시뮬레이션 값을 측정값처럼 씀 | evidence.md. 수치마다 출처(측정/계산/datasheet/시뮬레이션)를 구분해 적는다 |
| 오차율 기준을 틀림 | $\frac{\lvert 측정 - 이론 \rvert}{이론} \times 100\%$. 이론값이 0에 가까우면 차이(절대값)로 쓴다 |
| 유효숫자가 들쭉날쭉, 계산 결과를 계산기 자릿수 그대로 | 측정 분해능에 맞춘다. 같은 표 안에서 소수 자릿수를 맞춘다 (format.md) |
| 단위 빠짐, `5V`처럼 붙여 씀 | 도구: proof.py `[단위]` |
| 결론이 데이터와 다름 ("비슷하다", "거의 같다") | 차이를 수치로 쓴다 ("0.2 ns 차이", "12% 큼") |
| 그림·표 번호를 본문에서 틀리게 참조 | `@fig:`, `@tbl:`로만 참조 (도구: build.py가 번호를 매김, 풀리지 않으면 경고) |
| 오탈자, 조사 틀림(조건를), 게이트 이름 오타(NAD) | proofreading.md 순서대로. 도구: proof.py |
| 수식 기호를 `F0`처럼 일반 글자로 섞어 씀 | 기호는 전부 수식 $F_0$ (도구: proof.py `[기호]`) |
| 진리표 행 순서가 이진수 순서가 아님, 변수 순서(MSB)가 표마다 다름 | `logic.py truth --vars`로 만든 표만 쓴다. 첫 변수가 MSB |
| 회로도와 본문 식이 서로 다름 | 도구: `Circuit.verify()` (figures.md 회로 검증) |
