# 주제별 설명 틀 — 기초전자기학 MATLAB 과제

과제 문제가 아래 주제에 걸리면 해당 줄을 보고 쓴다. 문제 원문과 본인 코드가 우선이다. 코드에 없는 동작은 쓰지 않고, 표의 "확인할 것"은 결과 사진에서 실제로 보일 때만 문장으로 쓴다.
식은 교재 표기로 쓴다. MATLAB 함수 이름은 본인 코드에 있는 것만 `` `quiver` ``처럼 코드 글꼴로 쓴다 (`proof.py` `[표기]`).

## 한 문제의 흐름
1. 풀이 방법: 쓰는 식 하나둘. 기호의 뜻과 넣은 값(상수, 격자 범위, 간격)을 먼저 문장으로.
2. 코드 동작 원리: 입력(격자·상수) → 계산(어떤 식을 어떤 연산으로, 특이점 처리) → 그림(무엇을 어떤 함수로) 순서. 왜 그렇게 했는지 한 번씩 (원소별 연산 `./`, `meshgrid`, 0으로 나누는 점 처리).
3. 결과: 그림에서 읽은 값과 모양 → 이론과 맞는지 → 과제가 요구한 서술(장단점, 비교).

## 주제별
| 주제 | 보고서 식 | 동작 원리에서 설명할 것 | 결과에서 확인할 것 | 함정 |
|---|---|---|---|---|
| 함수 그래프·표본 간격 | $\operatorname{sinc}(t)$, $\Delta t$ | 간격별 배열, 특이점 값($t = 0$), `hold on`·`subplot` 배치 | 봉우리 높이·위치가 간격에 따라 어떻게 어긋나는지, 곡선 수가 조건과 맞는지 | 0/0을 그대로 둠, 간격 하나만 그림 |
| 벡터·좌표계 변환 | $x = r\sin\theta\cos\phi$, 단위 벡터 변환 행렬 | 각도 단위(rad), 변환 순서, 내적·외적 연산 | 크기 보존(변환 전후 $\lvert\mathbf{A}\rvert$ 같음), 직교성 | `cart2sph`의 고도각과 극각 $\theta$ 혼동 |
| 기울기·발산·회전 | $\nabla V$, $\nabla\cdot\mathbf{D}$, $\nabla\times\mathbf{H}$ | 격자 간격을 준 수치 미분 (`gradient(V, dx, dy)`), 중앙 차분 | 해석해와 격자점 몇 곳 비교, 경계에서 오차가 큰지 | 간격을 안 줘 단위 틀림, $\mathbf{E} = -\nabla V$ 부호 |
| 점전하·중첩 | $\mathbf{E} = \dfrac{q(\mathbf{r} - \mathbf{r}')}{4\pi\varepsilon_0 \lvert\mathbf{r} - \mathbf{r}'\rvert^3}$ | 전하마다 계산해 더함, 전하 위치의 $r = 0$ 처리 | 방향(양전하는 바깥), $1/r^2$로 줄어듦, 대칭 | 행·열과 $x$·$y$ 뒤바뀜, `quiver` 자동 크기 |
| 연속 전하 분포 | $\mathbf{E} = \int \dfrac{\rho_L\,dl'\,(\mathbf{r} - \mathbf{r}')}{4\pi\varepsilon_0 \lvert\mathbf{r} - \mathbf{r}'\rvert^3}$ | 원천을 작은 조각으로 나눠 합 (조각 수), `integral`·`trapz` | 조각 수를 늘려도 값이 그대로인지(수렴), 축 위 해석해와 비교 | 조각이 거칠어 값이 흔들림 |
| 전위·등전위선 | $V = \dfrac{q}{4\pi\varepsilon_0 r}$ | 전위 격자 → `contour`, 필요하면 $-\nabla V$로 전기장 | 등전위선과 전기력선이 수직, 전하 근처에서 촘촘함 | `axis equal` 없이 원이 타원으로 |
| Laplace 방정식 (경계값) | $\nabla^2 V = 0$, $V_{i,j} = \frac{1}{4}(V_{i+1,j} + V_{i-1,j} + V_{i,j+1} + V_{i,j-1})$ | 경계 조건 고정, 반복 갱신, 멈춤 조건(변화량 < 허용값) | 반복 횟수, 경계값 사이에서 매끈한지, 해석해(평행판·상자) 비교 | 경계를 매번 덮어씀, 수렴 전에 멈춤 |
| 영상법 | 접지 평면 위 $q$ → 대칭 위치 $-q$ | 영상 전하를 더한 중첩, 도체 영역은 그리지 않음 | 평면에서 $V = 0$, 전기장이 평면에 수직 | 도체 안쪽까지 필드를 그림 |
| 정자기장 (Biot–Savart) | $d\mathbf{B} = \dfrac{\mu_0 I\, d\mathbf{l}' \times \mathbf{R}}{4\pi R^3}$ | 도선을 조각으로 나눠 외적 합, `cross` | 오른나사 방향, 무한 직선 해석해 $\mu_0 I/(2\pi r)$와 비교 | 외적 순서 반대, $\mu_0$ 값 |
| 시간 변화·평면파 | $E_x = E_0\cos(\omega t - \beta z)$ | 시간 반복으로 그림 갱신(애니메이션) 또는 몇 시점 겹침 | 파장 $\lambda = 2\pi/\beta$, 진행 방향, 위상 속도 | $\omega$와 $f$ 혼동, 화면만 보고 주기 단정 |

## 자주 쓰는 MATLAB 함수의 설명 꼴
본인 코드에 있을 때만 한 번씩 이렇게 풀어 쓴다.
| 함수 | 설명 |
|---|---|
| `meshgrid(x, y)` | 격자점마다 $x$, $y$ 좌표를 담은 두 행렬. 행은 $y$, 열은 $x$가 바뀐다 |
| `quiver(X, Y, U, V)` | 격자점마다 $(U, V)$ 방향 화살표. 길이는 자동으로 맞춰져 상대 크기만 본다 |
| `contour(X, Y, V, n)` | $V$가 같은 점을 이은 선 $n$개 |
| `surf`, `mesh` | 격자 위 값을 높이로 한 곡면 |
| `gradient(V, dx, dy)` | 이웃 점 차이로 구한 편미분 (간격을 줘야 단위가 맞다) |
| `trapz`, `integral` | 사다리꼴 수치 적분 / 적응형 적분 |
| `hold on` | 다음 그림을 같은 축에 겹쳐 그린다 |
| `subplot(m, n, k)` | 창을 $m \times n$으로 나눠 $k$번째 칸 |
