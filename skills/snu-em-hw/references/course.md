# 기초전자기학 및 연습 — 과제 제출 규칙

출처: 과제 공지 (eTL). 과제마다 공지가 이 파일과 다르면 **공지가 우선**이고, 차이를 `courses/em/hwNN/requirements.md`에 적는다.

## 제출 (eTL)
| 항목 | 규칙 |
|---|---|
| 내는 것 | HW의 MATLAB 코드(m-file)와 결과 보고서를 **한 zip으로** |
| zip 이름 | `HW1_홍길동_2025-12345.zip` (과제 번호_이름_학번) |
| 결과 보고서 | `HW1_홍길동_2025-12345.pdf` — **PDF** (공지 예시의 학번 앞 공백은 오타로 보고 붙여 쓴다) |
| MATLAB 파일 | `HW1.m`, **첫 줄 `clc; clear;`** |

## 보고서 내용
- 학번, 이름을 반드시 적는다 (제목 블록에 들어간다).
- 문제마다 코드에 **영어 주석**을 반드시 단다 (m-file 안, 보고서에 옮긴 코드도 같다).
- 자기 코드의 **동작 원리**를 설명한다: 어떤 식을 어떤 순서로 계산하는지, 격자·적분 방법, 그림이 무엇을 보여 주는지.
- 분량, 양식은 자유.

## 이 skill의 처리
- 보고서는 다른 과목과 같은 엔진으로 `.docx`를 만들고, PDF로 바꿀 수 있으면(`--pdf`) 제출용 PDF와 zip까지 만든다 (`out/em/`).
  PDF 변환 도구가 없으면 사용자가 Word에서 `HW1_이름_학번.pdf`로 저장하고 `mcode.py pack`으로 zip을 만든다.
- 코드는 `mcode.py check`가 파일 이름, 첫 줄, 영어 주석, 문제 절(`%% Problem N`)을 검사한다.
