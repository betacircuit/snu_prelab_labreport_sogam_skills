# 처음 설정 — 사용자에게 물을 최소한의 정보

누가 쓰든 같은 스킬로 돌아가도록, 사람마다 다른 정보는 작업 폴더의 `profile.yaml`과 `courses/<과목>/course.yaml`에만 둔다.
작업을 시작할 때마다 먼저 확인하고, 빠진 것만 한 번에 묻는다. `$E`는 엔진 `scripts/` 폴더 (SKILL.md "경로 두 개").

## 1. 확인
```bash
python $E/setup_profile.py --check --course <과목>   # logic, circuit, seminar
```
`ok`가 나오면 바로 작업한다.
- `need:` 줄은 묻지 않고 처리한다.
  - 패키지: 안내된 `pip install -r …` (막히면 `--break-system-packages` 또는 `--user`), pandoc 설치.
  - 작업 폴더 없음: 현재 폴더에서 `python $E/setup_profile.py --init` (홈 폴더 자체면 `~/snu-reports`를 만들고 `--root ~/snu-reports --init`). 만든 곳을 한 줄로 알린다.
- `missing:` 줄이 나오면 그 질문들만 모아 **한 메시지로** 묻는다.

## 2. 묻는 것 (이것만)
| 언제 | 항목 | 필수 | 쓰이는 곳 |
|---|---|---|---|
| 처음 한 번 | 이름 | 예 | 제출 파일명, 제목 블록 |
| 처음 한 번 | 학번 (2025-12345) | 예 | 제출 파일명, 제목 블록 |
| 처음 한 번 | 학과 | 아니오 (기본 전기정보공학부) | 제목 블록 |
| 처음 한 번 | 관심 분야·트랙 | 아니오 | 소감문의 "나와 연결" |
| 실험 과목을 처음 쓸 때 | 조 번호 | 예 | 제목 블록 |
| 실험 과목을 처음 쓸 때 | 조원 이름 | 아니오 | 결과보고서 제목 블록 |
| 있으면 좋음 | 본인이 전에 쓴 보고서 파일 | 아니오 | 문체 기준 (`style_samples`) |

묻는 예:
```
처음이라 세 가지만 알려 줘.
1. 이름
2. 학번 (2025-12345 형식)
3. 논설실 몇 조야? 조원 이름도 알면 같이 (없으면 생략)
관심 분야나 전에 직접 쓴 보고서가 있으면 같이 줘도 돼. 문체를 맞추는 데 써.
```

묻지 않는 것: 서식, 글꼴, 파일명 규칙, 마감, 문항 범위. 이건 과목 규칙(`course.yaml`, `references/course.md`)과 수업 자료로 정한다.

## 3. 저장
```bash
python $E/setup_profile.py --name 홍길동 --student-id 2025-12345 [--department 전기정보공학부] [--track 회로]
python $E/setup_profile.py --course logic --team 7 --teammates "김철수, 이영희"
python $E/setup_profile.py --style-sample <본인 보고서 .txt 경로>
```
- 스크립트가 학번 형식을 검사한다. 틀리면 다시 묻는다.
- 작업 폴더가 git 저장소면 저장한 뒤 커밋하고 push한다. 다음부터는 묻지 않는다.
- 파일을 쓸 수 없는 환경(ChatGPT 웹 채팅 등)이면 이 대화에서만 기억하고, 끝에 아래 블록을 사용자에게 주면서 "다음엔 이걸 프롬프트에 같이 붙여 줘"라고 한다.
  ```yaml
  name: 홍길동
  student_id: 2025-12345
  logic: { team: 7, teammates: [김철수, 이영희] }
  ```

## 4. 지키기
- 이름, 학번, 조를 추측하지 않는다. 채팅 기록이나 파일명에서 보이더라도 한 번 확인받고 저장한다.
- 다른 사람의 정보(조원 학번 등)는 사용자가 준 만큼만 저장한다.
