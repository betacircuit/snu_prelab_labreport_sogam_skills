# 자주 하는 실수 — 회로이론 및 실험

쓰는 법은 엔진 `references/mistakes.md` 머리말과 같다.

## 계측기
| 실수 | 막는 법 |
|---|---|
| 멀티미터로 전류를 병렬로 잼, 전류 단자에 꽂은 채 전압을 잼 | 전류는 회로를 끊고 직렬. 측정 후 리드를 전압 단자로 되돌린다 |
| 저항을 회로에 꽂은 채·전원을 켠 채 잼 | 병렬 경로가 섞인다. 부품을 빼서 잰다 |
| RMS, 진폭, peak-to-peak를 섞어 비교 | DMM AC는 RMS, 스코프는 보통 Vpp·Vamp. 정현파만 $V_{rms} = V_p / \sqrt{2}$. 표 머리에 어느 값인지 적는다 |
| DMM의 AC 측정 대역을 넘는 주파수 | 저가 DMM은 수백 Hz–수 kHz까지. 그 위는 스코프로 |
| 함수 발생기 50 Ω 출력 임피던스를 무시 | 회로 저항이 수십–수백 Ω이면 분압이 생긴다. 출력 설정(50 Ω/High-Z)을 적고 입력은 회로에 물린 상태에서 잰다 |
| 스코프 프로브 부하 | 10x 프로브 ≈ 10 MΩ ‖ 10–15 pF. 고임피던스 노드·고주파에서 응답이 바뀔 수 있다 |
| 스코프 접지 클립 두 개를 다른 노드에 물림 | 두 접지는 내부에서 이어져 그 사이가 단락된다. 떠 있는 소자 전압은 CH1 − CH2 (Math)로 |
| 전원 공급기 공통 접지 누락 | 두 채널로 ±V를 만들 때 가운데를 GND로. 함수 발생기·스코프 접지와 회로 GND를 잇는다 |
| 위상차 부호(앞섬·뒤짐) 혼동 | $\phi = 360° \times f \times \Delta t$. 출력이 늦으면 음(뒤짐) |
| 부품 허용 오차 무시 | 저항 ±1–5%, 커패시터 ±10–20%. 실측 부품값으로 이론값을 다시 계산해 비교 (snu-circuit-lab) |
| 저항 색 띠를 거꾸로 읽음, 전해 커패시터 극성 반대 | 금·은 띠가 오른쪽. 전해 커패시터는 (−) 표시 쪽을 낮은 전위로 |
| 인덕터 직렬 저항(DCR) 무시 | 공진·Q가 이론과 다르면 DCR을 재서 넣는다 |

## 이론과 계산
| 실수 | 막는 법 |
|---|---|
| **$\omega$와 $f$ 혼동 (2π 누락)** | $f_c = \frac{1}{2\pi RC}$ [Hz], $\omega_c = \frac{1}{RC}$ [rad/s]. 단위를 수식에 쓴다 |
| dB 환산 | 전압비 $20\log_{10}$, 전력비 $10\log_{10}$. −3 dB ≈ 0.707배 |
| 시정수 해석 | $\tau = RC$ 또는 $L/R$. 1τ에 63.2%, 5τ에 99.3%. 10–90% 상승 시간 ≈ 2.2τ |
| 수동 부호 규약 위반으로 전력 부호가 틀림 | 전류가 + 단자로 들어가는 방향이 흡수. 방향을 회로도에 화살표로 |
| 테브난 등가에서 종속 전원까지 끔 | 독립 전원만 끈다 (전압원 단락, 전류원 개방). 종속 전원이 있으면 시험 전원을 쓴다 |
| 페이저 위상을 $\tan^{-1}$ 한 번으로 구해 사분면이 틀림 | 실수부가 음수인 구간을 나눈다: $\angle(a + jb) = \tan^{-1}(b/a)$ ($a > 0$), $a < 0$이면 ±180°를 더한다. 보고서에는 이 구간 나눔을 쓰고 계산 프로그램의 함수 이름(atan2, numpy.angle)은 쓰지 않는다 (notation.md). 위상은 도(°)로 통일 |
| 직렬·병렬 RLC 공식 혼동 | $\omega_0 = 1/\sqrt{LC}$는 같고, Q와 대역폭은 다르다. sympy로 전달함수부터 푼다 |
| op-amp 가상 단락을 feedback 없이·포화 상태에서 씀 | negative feedback이 걸리고 출력이 전원 레일 안일 때만. 반전 이득 $-R_f/R_{in}$, 비반전 $1 + R_f/R_{in}$ |
| op-amp 고주파·큰 신호 한계를 무시 | GBW로 고주파 이득이 줄고, slew rate로 큰 신호가 삼각파가 된다. 측정이 이론과 다르면 원인 후보 |
| 보드 선도 주파수 축이 선형, 측정 점 간격이 고름 | 주파수 축은 로그, 측정 점도 로그 간격 (decade당 3–5점) |

## 시뮬레이션 (LTspice·ngspice)
| 실수 | 막는 법 |
|---|---|
| 접지(노드 0) 없음 | 도구: `spice.py lint` |
| 단위 접두사: `M` = milli, `F` = femto | 메가는 `MEG`, 패럿은 `u`·`n`·`p`로 (`10u`). `1F`는 1 fF다. 도구: `spice.py lint` |
| AC 해석 진폭을 실제 신호로 착각 | `.ac`는 소신호(AC 1). 크기는 이득으로 읽는다 |
| `.tran` 최대 step이 커서 파형이 각짐 | 가장 빠른 변화의 1/100 정도로 |
| 시뮬레이션 그래프를 측정값처럼 씀 | 캡션에 "LTspice 시뮬레이션" (ltspice.md). 측정·계산·시뮬레이션을 한 표에서 열로 나눈다 |
| 이론·시뮬레이션·측정의 조건(부품값, 입력 진폭·주파수)이 서로 다름 | 같은 값으로 맞추고, 다르면 실험 방법에 밝힌다 |
