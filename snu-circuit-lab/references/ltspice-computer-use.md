# LTspice 화면 작업과 깨끗한 출력

LTspice GUI 작업은 현재 호스트가 제공하는 computer-use로 진행한다. 조작에 쓰는 화면 관찰과 보고서에 넣는 저장 이미지는 별개로 확인한다.

## Codex / Windows
1. 설치된 `computer-use` 스킬과 그 스킬의 초기화·API·확인 지침을 읽는다. 현재 플러그인은 `node_repl`에서 `@oai/sky`를 초기화하는 방식이다. 브라우저용 `cua_repl`의 native apps 비활성 상태와 혼동하지 않는다. 도구가 바뀌면 설치된 스킬 문서를 기준으로 한다.
2. `list_apps` 또는 `list_windows` 결과에서 LTspice 창을 하나 고른다. 창 ID/프로세스를 추측하지 않는다. 사용자 입력 감지 후에는 `get_window_state`를 먼저 다시 호출한다.
3. 대상 창을 활성화하고 화면을 다시 읽는다. 접근성에는 LTspice가 나오는데 이미지가 다른 앱이면 좌표 조작을 하지 않고 대상 창 활성화·재관찰부터 한다.
4. **관찰 → 한 동작 → 재관찰**로 파일 열기, Run, trace 추가, 축 범위·커서 설정을 진행한다. 메뉴 이름·단축키는 지금 보이는 UI에서 확인한다. 모달의 요소 인덱스가 작동하지 않으면 재관찰 후 실제 입력란 좌표 또는 확인된 키보드 이동을 쓴다. 텍스트를 입력하기 전 커서/선택 영역이 올바른 필드에 있는지 확인한다.
5. `.asc` 회로도와 `.raw`·`.log`의 분석 조건, 노드 이름, 축 단위, 파형 채널이 검증한 파일과 맞는지 확인한다. GUI에 다른 파일이 열려 있다는 이유로 그 파형을 재사용하지 않는다.

## Claude 및 다른 호스트
현재 호스트에 제공된 computer-use 도구로 같은 관찰·한 동작·재관찰 흐름을 사용한다. Codex의 패키지 경로나 도구 이름을 Claude에 강제하지 않는다. GUI 도구가 없으면 사용 가능한 LTspice MCP의 화면 출력 기능을 확인한다. GUI/MCP 출력이 모두 불가능한 경우에만 필요한 캡처와 파일명을 묶어 사용자에게 요청한다. 배치 수치 확인은 그동안 진행한다.

## 포인터·후광을 남기지 않는 저장 순서
1. **앱 자체 출력 우선.** 설치된 LTspice 26 Windows 파형 창에서 `Tools → Write image to .emf file` 및 `Copy Graph Image to Clipboard`를 실제로 확인했다. 버전마다 메뉴를 다시 확인한다. EMF는 LTspice가 파형·축·라벨 자체를 출력하므로 computer-use 화살표나 클릭 후광을 피할 수 있다.
2. `Write image to .emf file`로 해당 과제 `figs/` 안 새 경로에 저장한다. 파일 생성과 크기를 확인한다. EMF를 PNG로 변환할 때는 벡터를 렌더링하고, 파형 좌표나 숫자를 다시 그리지 않는다. 과목 스킬의 [scripts/render_emf.ps1](../scripts/render_emf.ps1)가 System.Drawing으로 비율을 유지해 렌더링한다. 변환 후 저장 PNG를 실제로 열어 축·라벨·범례를 확인한다. 내보내기 설정에 따라 흑백이 될 수 있다. 두 채널이 같은 검정 실선으로 나와 구별하기 어려우면 색/선 모양 출력 설정 또는 이미지 복사 경로로 다시 얻는다.
3. 클립보드 복사를 사용한다면 방금 LTspice가 복사한 그래프임을 확인하고 그 이미지만 저장한다. 기존 클립보드 내용이나 도구의 화면 관찰 이미지를 그래프 출력으로 오인하지 않는다.
4. 앱 출력이 불가능한 경우에만 화면 캡처를 쓴다. 메뉴·툴팁·대화상자를 닫고, 지원되는 도구로 포인터를 파형·축·측정 목록 밖의 빈 영역으로 옮겨 후광이 사라진 것을 확인한 다음 캡처한다. 직접 포인터 이동 API가 없으면 현재 도구가 지원하는 방식만 사용한다. 존재하지 않는 '커서 숨기기' 옵션을 지어내지 않는다.
5. 저장 파일에서 화살표, 파란 후광, 메뉴, 다른 앱, 잘린 축, 빠진 단위가 하나라도 보이면 다시 얻는다. 파형을 가린 화살표를 인페인팅하거나 덧칠해서 삭제하지 않는다. 화면 밖 장식만 자르는 경우에도 모든 축·채널 이름·측정 목록을 보존한다.

computer-use를 썼다는 사실과 별개로, 최종 보고서에는 검토한 출력 파일만 넣는다. 조작 로그의 작은 썸네일을 최종 그림으로 쓰지 않는다.
