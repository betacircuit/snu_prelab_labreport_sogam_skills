# LTspice 화면 작업과 깨끗한 출력

LTspice GUI 작업은 현재 호스트가 제공하는 computer-use로 진행한다. 조작에 쓰는 화면 관찰과 보고서에 넣는 저장 이미지는 별개로 확인한다.

## 화면 준비

1. 현재 호스트의 computer-use 문서에서 앱 선택·입력·화면 저장 방법을 확인한다. 실제 창 목록에서 LTspice 창을 골라 활성화하고, 다른 앱이 보이면 조작하지 말고 대상을 다시 확인한다. 사용자가 조작하는 동안에는 입력을 멈추고 재개할 때 화면을 다시 읽는다.
2. 화면을 확인한 뒤 파일 열기, Run, trace 추가, 축·측정 커서 설정을 진행한다. 메뉴 이름과 단축키는 화면에서 확인한다. 표시한 회로와 파형이 검증한 `.asc`·`.raw`·`.log`의 분석 조건, 노드, 채널, 축 단위에 맞는지 확인한다.
3. GUI가 없으면 LTspice MCP에 실제 화면을 얻는 기능이 있는지 확인한다. 실제 화면을 얻을 수 없는 동안에는 수치 검증과 원고를 진행하고, 캡처가 필수이면 필요한 화면을 묶어 요청한다.

## 보고서에 넣는 그림

1. **회이실 예비·결과보고서의 LTspice 회로도·파형 그림은 기본적으로 실제 GUI 화면을 캡처한다.** LTspice가 그린 회로도·파형의 배경, 켜 둔 그리드, 채널 색, 축·단위, 측정 커서와 숫자 창을 그대로 보존한다. 회색 회로도나 검은 파형 배경이 보고서 서식 때문에 흰색으로 바뀌지 않게 한다. RAW 재플롯·모사 이미지·흑백 EMF를 화면 캡처 대신 넣지 않는다.
2. 메뉴와 툴팁을 닫고 포인터를 툴바나 그림 바깥으로 옮겨 클릭 후광이 사라진 뒤 캡처한다. **제외하는 것은 조작 포인터와 후광뿐이다.** LTspice 측정 커서의 선과 수치 창은 남긴다. 포인터가 화면을 가리면 다시 캡처한다. 필요한 경우 바깥 여백만 잘라내고 덧칠·인페인팅은 하지 않는다.
3. 별도 비교 그래프나 내보낸 이미지가 필요한 경우에는 LTspice의 `Write image to .emf file`이나 `Copy Graph Image to Clipboard`도 쓸 수 있다. 현재 버전의 메뉴에서 확인하고, EMF는 [render_emf.ps1](../scripts/render_emf.ps1) 등으로 렌더링한다. 서로 다른 채널이 구분되는지 확인한다. RAW 재플롯이 필요하면 별도 그래프로 표시한다.
4. 저장 이미지와 **최종 PDF 속 그림**을 각각 열어 배경·그리드·채널·축·단위·커서 창이 보이고 조작 포인터가 없는지 확인한다. 시뮬레이션 지시문은 읽기 쉬운 자리로 옮기되 조건을 바꾸지 않는다. 보고서에는 선명한 최종 이미지를 넣는다.
