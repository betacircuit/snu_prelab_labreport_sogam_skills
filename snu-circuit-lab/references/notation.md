# 수식·기호 표기 — 회로이론 및 실험

교재와 수업이 쓰는 표기로 쓴다. 계산은 sympy·numpy·LTspice로 해도 보고서에는 **식과 값만** 남긴다.
계산 프로그램의 함수·라이브러리 이름(atan2, numpy.angle, linspace, unwrap …)은 본문과 수식에 쓰지 않는다 (`proof.py` `[표기]`, 빌드가 멈춘다).

## 기본 기호
| 대상 | 쓰는 꼴 | 쓰지 않는 꼴 |
|---|---|---|
| 시간 영역 신호 | 소문자 $v(t)$, $i(t)$, $v_o(t)$ | $V(t)$ |
| 페이저 | 대문자 $\mathbf{V}_o$ 또는 $V_o$, 극형식 $V_m\angle\theta$ | `V_o = 2.1*exp(1j*0.3)` |
| 허수 단위 | $j$ ($j\omega$) | $i$ ($i$는 전류) |
| 전달 함수 | $H(j\omega) = \mathbf{V}_o / \mathbf{V}_s$, 크기 $\lvert H\rvert$, 위상 $\angle H$ | `abs(H)`, `angle(H)` |
| 주파수 | $f$ [Hz], $\omega = 2\pi f$ [rad/s]. 식마다 어느 쪽인지 단위를 붙인다 | $f$와 $\omega$를 섞어 대입 |
| 데시벨 | $20\log_{10}\lvert H\rvert$ [dB] (전압비), 전력비 $10\log_{10}$ | `20log`, `20*np.log10` |
| 크기 구분 | $V_p$ (진폭), $V_{pp}$, $V_{rms}$. 표 머리에 어느 값인지 | 그냥 "전압 2 V" |
| 시정수·특성값 | $\tau = RC$, $\omega_0 = 1/\sqrt{LC}$, $f_c$, $Q$ | `tau`, `w0` |
| 단위 접두사 | µF, µs (마이크로는 µ), kΩ, MΩ | uF, us, K옴 |

## 위상
위상은 $\tan^{-1}$로 쓰고, 분모(실수부)가 음수가 되는 구간을 나눠 밝힌다. 위상은 도(°)로 통일한다.

```
위상차는 출력 위상에서 입력 위상을 뺀 값이다.

$$\angle H_R = -\tan^{-1}\frac{\omega L_1/R_1}{1 - \omega^2 L_1 C_1} \quad (\omega < \omega_0)$$

$\omega > \omega_0$에서는 분모가 음수가 되므로 위 값에서 180°를 뺀다.
```

- 분자·분모 부호로 어느 사분면인지 정한다: 실수부 $a > 0$이면 $\angle(a + jb) = \tan^{-1}(b/a)$, $a < 0$이면 ±180°를 더해 −180°–180° 안으로.
- $\omega = \omega_0$처럼 실수부가 0이 되는 점은 ±90°라고 따로 쓴다.
- 위상차의 부호와 앞섬·뒤짐을 함께 쓴다: "출력이 입력보다 32° 뒤진다($\phi = -32°$)". 측정은 $\phi = -360° \times f \times \Delta t$ (출력이 늦으면 음수).
- 보드 선도 위상이 −180°에서 +180°로 뛰는 것은 표시 범위 탓이다. 그래프에서는 이어지게 그린다 (`bode.py`가 처리한다).

## 계산 과정을 보이는 법
- 기호식 → 대입 → 결과 (writing.md). 계산 도구 이름 대신 "식 (3)에 $f = 1\ \text{kHz}$를 대입하면"처럼 쓴다.
- 여러 주파수에서 같은 식을 쓰면 일반식은 한 번, 값은 표로.
- 시뮬레이션 값은 "LTspice 시뮬레이션"이라고 밝힌다. 프로그램 이름을 쓰는 것은 LTspice(교재가 쓰는 도구)뿐이다.

## 용어
번역이 와닿지 않는 말은 영어로 둔다 (writing.md 용어): op-amp, negative feedback, offset, slew rate, GBW, decoupling, bypass.
한국어로 바로 통하는 말은 한국어로: 이득, 위상, 차단 주파수, 공진 주파수, 시정수, 가상 단락, 반전·비반전 단자.
